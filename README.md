# Lucas Marques — Creative Developer & AI Creator

Biosite autoral em React + Vite para apresentar serviços de desenvolvimento, inteligência artificial, direção visual e motion.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run build
```

As animações usam CSS e APIs nativas do navegador, com suporte a `prefers-reduced-motion` e sem bibliotecas de motion em runtime.
